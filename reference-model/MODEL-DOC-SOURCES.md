# Model-Document Sources — v0.1 (2026-07-15)
Status: draft source map for the generation library. License gate
(Roadmap §1) runs per source BEFORE anything enters the library:
free-to-download is not free-to-ship-derivatives-of, per customer,
commercially. Model docs are generation seeds only — the judge
never sees them (no-canonical-artifact ruling, 2026-07-13, stands).

## Harvest rule
Per model doc: skeleton extracted (structure, never verbatim gated
content), provenance recorded (source, URL, license, date), traced
to the authority canon of its criterion. First flow:
talk-track-from-transcripts, after ref-board-003.

## Corpus-entry provenance (`origin` field) — firewall convention (2026-07-16)
Every corpus/evidence entry MAY carry an `origin` field, closed enum:
`company-native | ladder-generated | external-template | operator-modified |
post-intervention-natural`. Absent field = company-native. The classifier STRIPS
`origin` before the judge (blindness; scripts/classifier/provenance.ts) and DISCLOSES
it at the board where not company-native. Per the GAP-CLASS-DOCTRINE firewall addendum,
an approved draft is ingested as a clean adopted document (generation markers removed
from the body, recorded in `origin`) so body text never re-announces provenance to the
judge.
