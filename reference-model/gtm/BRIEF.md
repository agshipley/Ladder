## 0. Method note

Authorities gathered 2026-07-08. Per protocol §2, the genre ladder was enumerated first; GTM has **no primary/statutory rung** for its operating content (outbound-communication law — CAN-SPAM/TCPA-class — is real but routes to Compliance). The category's citable authorities are therefore named practice frameworks, benchmark publishers, and investor scrutiny tests — per Task 1 v2, this genre profile takes more expert-authored weight without penalty. Provenance discipline applied here: **named, versioned frameworks and benchmark publishers count as citable authorities** (they are the "practice frameworks / model documents" of this domain); **diffuse norms** with no nameable source are tagged expert-authored. Boundary rules B-7, B-8, B-9 from TAXONOMY.md govern scope; B-8 and B-9 receive resolution evidence here (§4).

One structural constraint honored throughout: Sprint L's Task 1 gates the SDR loop on four prerequisites — CRM, scheduler, talk track, KPIs. Those four must fall out of this category's completeness criteria as first-class artifacts, and they do (GTM-03, GTM-04, GTM-06). The concept doc's GTM worked example (transcripts-without-talk-track = red; pipeline-in-Excel = red; no scheduler = orange; unsegmented KPIs = orange) is treated as operator-authored seed criteria and is preserved, with one tension against external canon logged honestly (Conflict C-3).

## 3. Conflicts and proposed arbitrations

NOTE (2026-07-15): §3–§8 are the arbitration record of the v1 grain and argue in retired IDs; they are preserved as argued. Current homes per the v2 addendum: C-3 -> GTM-11 (interim-tool-thin); C-5 -> GTM-13/15/16 multi-homing; E-4 -> GTM-22; E-5's elements per the v2 map; §5's marketing subcategory -> GTM-10. Where this note and the old prose disagree, this note governs.

**C-1 — Methodology prescription.** The methodology genre argues for specific frameworks by ACV band (MEDDPICC >$50K, SPICED for lifecycle, lightweight for SMB). The reference model is vendor-agnostic by principle. **Arbitration:** the criterion is *a named, written qualification discipline reflected in the system of record* — any framework, including homegrown. The Korn Ferry finding (formalized methodology ↔ 27% win-rate delta; only 30% consistency) supports scoring the discipline's existence, never its brand.

**C-2 — When positioning formalizes.** Dunford's own caveat: pre-PMF, over-nailed positioning is premature — let the market pull. The discovery canon simultaneously demands a documented ICP from the first stranger-sale. **Arbitration:** Band 1 requires the documented ICP and a positioning *thesis with revision history*; revision evidence is a maturity *positive* (the inconsistency detector must not flag a superseded positioning doc as contradiction when it is versioned supersession).

**C-3 — The CRM bar.** External founder-led canon tolerates spreadsheet pipelines pre-first-hire; the concept doc's worked example scores pipeline-in-Excel as a red tile. These genuinely disagree at the earliest edge. **Arbitration:** Band 1 as declared (seed-*funded*, building toward a matured GTM function and the SDR loop) adopts the concept doc's bar: a functional system of record is required, spreadsheet-only is red — with the tile copy naming the fix as migration (the maturity layer can seed a CRM structure *from* the spreadsheet, per the concept doc). A future pre-seed band would relax this; no speculative band is created now. **9E-b supersession (operator, 2026-07-11):** the spreadsheet-only outcome is re-shaped — it scores THIN at the system-of-record ELEMENT grain (pipeline practice evidenced; the CRM-as-system-of-record element underdeveloped; fix = migration), NOT red at the subcategory grain. RED is reserved for no pipeline record found anywhere. loop-ready still requires evidence-found on GTM-03 — thin blocks the SDR-loop derivation, unchanged. Landed in CRITERIA-SCHEMA.yaml GTM-03 v1.1.

**C-4 — Benchmark variance.** Payback bars range <12mo to 24+ by motion; NRR "good" ranges 100–120%+ by source and segment. **Arbitration:** benchmark *values* never gate tile color. The scored criteria are measurement existence, definitional honesty, and segmentation; current benchmark bands are displayed as context annotations with source and date. This also keeps the model's promise that maturity is operational readiness, not performance.

**C-5 — Playbook location.** The documented sales motion is claimed by both GTM-03 (motion) and GTM-04 (enablement artifacts). **Arbitration:** GTM-03 owns the *process* documentation (stages, evidence, forecast); GTM-04 owns the *conversation* artifacts (talk track, objections, discovery guide, pricing). The classifier maps a monolithic "sales playbook" doc to both without double-penalizing absence.

## 6. Elevations to the operator

**E-1 — Capability vs. performance scoring (the big one).** *Position A:* the board scores measurement capability only — metrics defined, tracked, segmented — and shows benchmark bands as annotations. Keeps Ladder an operational-maturity product, avoids the board calling a healthy-but-early company red on numbers, and matches "maturity ≠ documentation completeness… fit-for-stage." *Position B:* some performance floors are themselves maturity facts (a company that measures churn perfectly at 15%/mo has a mature dashboard on a dying motion) — add a narrow "metric distress" annotation layer, still never tile color. **My lean:** A for tile color, with B's distress annotations as non-scoring context. This decision propagates to every metric-bearing category (Finance next), so it deserves a boundary-registry entry.
